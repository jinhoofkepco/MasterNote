# 작도 메모

기존 교재 또는 메모의 **작도** 버튼을 누르면 해당 페이지·메모에 연결된 작도장이 열립니다.
손필기와 작도는 별도 자료입니다. 기존 필기 좌표·저장 형식은 바꾸지 않습니다.
메모 안에서는 같은 평면에서 함께 확대·이동하며, 필기/도형 모드로 조작 대상을 구분합니다.
지우개·삭제·실행 취소는 서로의 자료에 영향을 주지 않습니다.

## 색·선 종류와 조건 조절

- 도형을 선택한 뒤 색을 누르면 선택한 대상이 바로 바뀝니다. 선택하지 않았으면 다음 도형의 색입니다.
- 실선(―)·점선(– –)·점점선(···) 아이콘은 선택한 선분·원 또는 다음에 그릴 선분·원에 적용됩니다.
- 길이·반지름·방향각·수선 거리 조건은 그림에 연한 파랑으로 표시합니다. 숫자를 누르면
  바로 옆에 작은 조절 메뉴가 열리고, ±를 누를 때마다 조건을 계산해 저장합니다.
- 기본 간격은 길이 0.1cm, 각도 1°입니다. 간격 버튼으로 1cm/5°도 고를 수 있습니다.
  숫자 직접 입력 후 ‘입력 적용’도 가능합니다. 원은 반지름을 조절하며 둘레를 함께 보여 줍니다.
- 조건 목록에서는 제목을 누르면 해당 항목 아래로 조절부가 펼쳐집니다. 체크박스는
  조건을 삭제하지 않고 잠시 끄고 켭니다. 꺼진 상태에서 숫자를 바꾸면 설정 값만 변경됩니다.
- 다른 고정 조건과 맞지 않거나 해를 찾지 못하면 이전 도형·값을 유지합니다.
  화면의 작은 메뉴는 도형을 밀지 않으며, 제목을 끌어 옮길 수도 있습니다.

## 가장 먼저 해 볼 것

1. 작도 → 예제 → **10cm + 6cm 연결 막대**를 여세요.
2. O는 고정점, P와 Q는 따로 만든 두 점에 ‘일치’를 지정한 것입니다.
3. R을 끌면 OP는 10cm, QR은 6cm인 채 다른 점들이 함께 움직입니다.
4. 조건 목록에서 ‘두 점 일치’를 끄면 연결이 풀립니다. 겹친 점을 차례로 눌러
   원하는 점만 선택한 다음 끌면 따로 움직일 수 있습니다.
5. 반지름이나 길이 조건의 숫자를 바꾸면 나머지 점들이 새 조건에 맞춰 움직입니다.

‘10’이라는 숫자가 같다고 두 길이를 자동으로 묶지는 않습니다.
항상 같이 변해야 하는 길이는 두 선분을 선택해 **같은 길이 유지**를 지정하세요.

## 직접 그리기

- 점: 위치 한 번. 선분: 시작과 끝 두 번. 원: 중심과 원 위의 위치 두 번.
- 기존 점을 눌러 선분을 만들면 같은 점을 공유합니다. 따로 만든 두 끝점을 나중에
  연결하려면 선택 모드에서 점 두 개 → 조건 추가 → 두 점 일치를 사용하세요.
- 선택 모드에서는 대상 여러 개를 차례로 선택합니다. 빈 곳을 누르면 선택 해제입니다.
- 선분 하나 → 길이·수평·수직, 원 하나 → 반지름, 점 하나 → 고정·고정 풀기.
- 선분 두 개 → 평행·수직·같은 길이·각도·높이·교점.
- 점과 직선 → 직선 위에 놓기·수선 거리·수선과 수선의 발 만들기.
- 점과 원 → 원 위에 놓기. 방향을 모르는 10cm 선분은 중심점과 반지름 10cm 원을
  만든 뒤 끝점을 원 위에 놓는 방식으로 표현할 수 있습니다.
- 조건 목록 → 숫자 변경 / 잠시 끄기 / 다시 켜기 / 삭제.
- 측정은 현재 값을 읽을 뿐 모양을 고정하지 않습니다. 두 점 거리, 두 선 각도,
  삼각형 넓이, 원의 넓이, 점과 직선 사이 수선 거리를 확인할 수 있습니다.
- 점 이동, 조건 변경, 삭제는 되돌리기·다시 실행을 지원합니다.

## 보내 주신 사다리꼴

예제 두 번째 항목에 윗변 6cm, 아랫변 15cm, 왼쪽 변 15cm, 높이 13.3cm,
평행한 두 밑변, 두 대각선의 교점, 왼쪽 변에 내린 수선을 넣었습니다.
수선 ㅁㅂ을 선택해 측정하면 **3.8cm**입니다.

조건 목록의 높이를 13.3에서 14로 바꾸면 다른 조건은 유지되고 수선은 **4cm**가 됩니다.
같은 숫자 15가 붙은 두 변도 독립된 조건입니다. 어디를 묶고 어디를 바꿀지 직접 정합니다.

## 수학과 저장의 약속

- 내부 좌표는 두 축 모두 같은 cm 단위입니다. 화면 확대가 길이·각도를 바꾸지 않습니다.
  화면에 표시한 1cm가 실제 자로 잰 기기 화면의 1cm라는 뜻은 아닙니다.
- 고정 조건을 만족하는 좌표를 수치적으로 계산합니다. 계산에 실패하면 마지막 정상
  상태를 유지합니다. ‘해를 찾지 못함’은 수학적으로 불가능함을 증명한 뜻이 아닙니다.
- 각도 조건은 두 선분의 **시작→끝 방향 사이 0~180°**입니다. 삼각형 내부각과
  반대 방향일 수 있으므로 선분을 그린 방향을 확인하세요. 직선 조건은 연장선을 포함합니다.
- 현재 제한은 점 60개, 조건 100개, 점·선·원 합계 180개입니다. 범용 CAD의 모든
  접선·호·다각형 조건이나 기호식 증명을 제공하는 버전은 아닙니다.
- 작도는 현재 기기에 자동 저장되며 전체 앱 백업·복원에 포함됩니다.
  메모당 도형판은 하나이며, 메모 안의 도형은 기존 실시간/Telegram 전송 경로를 사용합니다.
  학생 쪽 저장은 자동 전송하고, 선생 쪽 변경은 명시적으로 발행할 때만 보냅니다.
  서로 다른 변경이 있으면 어느 쪽 도형으로 맞출지 확인합니다. 별도 전체화면 작도장은 로컬 자료입니다.
- 색·선 종류·조건의 값 및 켜짐/꺼짐도 저장·동기화됩니다. 새 선 종류를 사용하려면
  폰과 태블릿 모두 같은 업데이트를 적용하세요. 기존 실선 자료의 형식·동기화 해시는 유지합니다.
- 기존 앱을 삭제하거나 데이터를 지우지 마세요. 기존 서명·패키지와 같은 release APK를
  `adb install -r` 또는 Android 업데이트 설치로 적용합니다. DEV APK는 업데이트용이 아닙니다.

## 코드 근거와 검증

GitHub의 SolveSpace·FreeCAD를 검토한 뒤, 이번 구현에는 오래된 Apache Commons Math
3.6.1의 LM·SVD 수치 계산 코드를 실제 의존성으로 사용했습니다.
기하 조건·분기 유지·편집 UI는 새 Kotlin 코드이며 완성된 CAD 엔진을 가져온 것은 아닙니다.
정확한 출처·라이선스·경계는 [코드 출처 기록](../construction/core/PROVENANCE.md)에 있습니다.

자동 검증은 계산·저장·도형 편집 명령 및 Android 편집창의 저장/재열기/드래그/되돌리기/
치수 변경/동시 저장 충돌을 포함합니다. 기기 연결 전에는 실제 S Pen 조작과 설치를
검증했다고 간주하지 않습니다.
